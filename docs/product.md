Тренажер для Frontend разработчика на React
Позволяет практиковаться в ответах на вопросы с собеседований по React и Frontend разработке. Включает в себя различные темы, такие как компоненты, состояние, хуки, маршрутизация и многое другое. Пользователи могут проходить тесты, получать обратную связь и улучшать свои навыки в реальном времени.

MVP:
 - Создание интерактивного интерфейса для прохождения тестов по React.
 - Включение различных тем и категорий вопросов.
 - Возможность отслеживания прогресса пользователя и предоставления обратной связи.

Дополнительные функции:
 - Онлайн кодинг-редактор для практики написания кода.
