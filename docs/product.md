Тренажер для Frontend разработчика на React
Позволяет практиковаться в ответах на вопросы с собеседований по React и Frontend разработке. Включает в себя различные темы, такие как компоненты, состояние, хуки, маршрутизация и многое другое. Пользователи могут проходить тесты, получать обратную связь и улучшать свои навыки в реальном времени.

MVP:
 - Создание интерактивного интерфейса для прохождения тестов по React.
 - Включение различных тем и категорий вопросов.
 - Возможность отслеживания прогресса пользователя и предоставления обратной связи.

Уточнения по MVP:
 - Вопросы открытые, с текстовым ответом (не тесты с вариантами, не флеш-карты).
 - Проверка ответа — с помощью LLM: AI оценивает ответ пользователя и даёт обратную связь.
 - Авторизация пользователя обязательна — прогресс хранится на сервере, а не локально.
 - Наполнение базы вопросов — через админ-интерфейс (CRUD для вопросов и тем).
 - Отслеживание прогресса включает: процент правильных ответов по темам, историю прохождений во времени, повторение вопросов с ошибками (spaced repetition).
 - Технологический стек: Next.js (фронтенд и бэкенд в одном приложении).

Дополнительные функции:
 - Онлайн кодинг-редактор для практики написания кода (детали исполнения кода пока не определены, вопрос отложен).
